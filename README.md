# Spring Boot Projects

This repository contains a collection of Spring Boot projects created while learning and practicing Java Spring Boot development.

The projects cover different concepts and technologies within the Spring ecosystem, including REST APIs, Spring Web, Spring Data JPA, and Spring JDBC.

## Projects

### 1. SpringBootRest
A Spring Boot project focused on building and working with RESTful APIs.

### 2. SpringBootWeb
A Spring Boot project focused on web application development using Spring Web.

### 3. SpringDataJPA
A Spring Boot project demonstrating database interaction using Spring Data JPA and Hibernate.

### 4. SpringJDBC
A Spring Boot project demonstrating database operations using Spring JDBC.

### 5. jobapp
A Spring Boot application demonstrating the development of a job-related application using Spring Boot.

## Technologies Used

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Spring JDBC
- Hibernate
- Maven
- REST APIs
- SQL Databases

## Purpose

This repository serves as a collection of my Spring Boot learning projects and practical exercises. Each project focuses on different concepts of backend development using the Spring ecosystem.
